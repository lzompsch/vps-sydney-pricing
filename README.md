## 退款规则的真实红线：14 天不是万能保险

V.PS 支持 VPS 产品 **14 个自然日内**退款，通过提交工单办理。但 FAQ 和 Pricing 页里藏着一批例外条款，踩中任何一条就拿不回钱了，这些恰恰是大多数测评文章不会展开的部分：

1. **流量超过 10 GB 就失去退款资格**。哪怕只用了 6 天，只要月流量表跑了 10GB 以上，退款窗口就关了。想先试试再退的人，测试期别挂大流量任务。
2. **每个账号终身只能退一次**。上次买别的套餐退过款，这次再退就不行了。
3. **加密货币和银行电汇付款不退款**。想保留退款权利，用 PayPal 或信用卡下单。
4. 续费订单、闪购特价机、申请过换 IP、开通过 BGP/IX 服务、服务发生过账户转移、IP 被列入黑名单（Spamhaus、blocklist.de、中国 GFW 等）的情形，全部不可退。

实操建议很直接：付款方式选 PayPal，开通后先跑一两天轻量测试，确认线路和性能达标再部署正式业务，14 天内一切还来得及。

另外管理功能都在 client area 里完成：重启、重装、升降配，或者全走 API 脚本化。Performance 和 Edge 系列还送面板内的快照备份（Edge 1 个槽位、Performance 2 个），不过这两个系列目前没有悉尼节点，选悉尼的话备份得自己另想办法。
